# Обновление: Значения по умолчанию для типа и цели разбраковки

## Дата: 2026-06-28

## Изменения

### Тип разбраковки и Цель разбраковки - теперь с дефолтными значениями

**Проблема:** Поля "Тип разбраковки" и "Цель разбраковки" были обязательными и требовали наличия в файлах данных.

**Решение:** Теперь эти поля имеют значения по умолчанию и не требуют обязательного присутствия в файлах.

### Дефолтные значения

- **Тип разбраковки:** `"Разбраковка NI"` (по умолчанию)
- **Цель разбраковки:** `"ПР-ОВ"` (по умолчанию)

### Поведение

1. **Если поля отсутствуют в файле:**
   - Используются дефолтные значения
   - Парсинг проходит успешно
   - В UI форме отображаются дефолтные значения

2. **Если поля присутствуют в файле:**
   - Используются значения из файла
   - Переопределяют дефолтные значения

3. **В UI форме:**
   - Можно выбрать любой вариант из выпадающих списков
   - Доступны все варианты типов разбраковки:
     - "Разбраковка NI"
     - "Разбраковка FORM"
   - Доступны все варианты целей:
     - "ПР-ОВ"
     - "ОКР"

### Технические детали

#### Модель данных (`models/crystal_data.py`)

```python
# До
sorting_type: str = Field(..., min_length=1)  # Обязательное
sorting_target: str = Field(...)              # Обязательное

# После
sorting_type: str = Field(default="Разбраковка NI", min_length=1)
sorting_target: str = Field(default="ПР-ОВ")
```

#### Парсер (`parsers/base.py`)

```python
defaults: dict[str, Any] = {
    # ...
    "sorting_type": "Разбраковка NI",  # Дефолтное значение
    "sorting_target": "ПР-ОВ",          # Дефолтное значение
    # ...
}
```

#### UI форма (`ui/edit_form.py`)

```python
# Автоматическая установка дефолтных значений если поля отсутствуют
target_value = str(values["sorting_target"]) if values.get("sorting_target") else "ПР-ОВ"
current_type = str(values.get("sorting_type", "Разбраковка NI"))
```
