# Changelog

Все заметные изменения в проекте SimpleMeasure будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- 🔐 Безопасное хранение credentials через системный keyring
- 🔄 Retry механизм для API запросов с exponential backoff
- ✅ Валидация форматов файлов перед парсингом (размер, MIME-type, расширение)
- 📊 Прогресс-бар для загрузки больших файлов (>1 MB)
- 📝 Настраиваемые уровни логирования (DEBUG, INFO, WARNING, ERROR, CRITICAL)
- 🧪 Comprehensive test suite с pytest-qt для UI тестов
- 📖 Полная документация в README.md
- 🔧 pytest.ini для удобной конфигурации тестов
- ⚙️ Значения по умолчанию для типа и цели разбраковки

### Changed
- Логирование теперь поддерживает настройку уровня через .env (LOG_LEVEL)
- API client теперь использует urllib3 Retry для автоматических повторов
- Settings теперь приоритезирует keyring над .env файлом
- Улучшена обработка ошибок с более информативными сообщениями
- **Тип разбраковки** и **Цель разбраковки** теперь необязательные поля с дефолтами:
  - `sorting_type` по умолчанию: "Разбраковка NI"
  - `sorting_target` по умолчанию: "ПР-ОВ"
  - Можно не указывать в файлах данных
  - Можно изменить в UI форме

### Improved
- Ротация логов с детальными настройками (5 файлов × 5 MB)
- Снижен уровень шума от внешних библиотек (urllib3, requests)
- Улучшена безопасность: HTTPS only, proper timeout handling
- Расширенные тесты API с mock scenarios
- Упрощена структура файлов данных (меньше обязательных полей)

### Security
- Credentials больше не хранятся в plain text (используется keyring)
- Валидация файлов против потенциально вредоносных inputs
- Ограничение максимального размера файлов (100 MB)
- MIME-type проверка для предотвращения загрузки неверных форматов

## [1.0.0] - 2024-XX-XX

### Added
- Первый релиз SimpleMeasure
- Парсинг данных из Excel, CSV, TXT файлов
- REST API интеграция с JWT авторизацией
- PyQt6 GUI с тёмной темой
- Pydantic валидация данных
- Базовое логирование
- PyInstaller сборка

### Features
- Автоматическое определение формата файла
- Форма редактирования с тремя вкладками (Параметры, Показатели, Нормы)
- Диалог подтверждения перед отправкой
- Асинхронная отправка данных (QThread worker)
- Сохранение последнего открытого файла
- Адаптивный UI с соотношением 16:9
